# Betalink · Hospitality Cloud Solutions

Modern, high-performance landing page for **Betalink Snc** (Andalo, Trentino, Italy) — developing next-generation cloud management software for hotels, restaurants, and alpine hospitality.

## Features
- **Bilingual Experience:** Instant switching between Italian (`IT`) and English (`EN`) with full localization dictionary and persistence.
- **Option A Alpine Trust Design:** Clean, authoritative color system (`#0A2540` authority navy, `#0066CC` trust cobalt, `#059669` compliance emerald) with crisp typography and glassmorphism.
- **Client Showcase & Verification:** Highlights real 4-star hotels, resorts, and alpine chalets across the Paganella Plateau and Dolomites (Hotel Diamant, Hotel Adler, Hotel Panorama, Hotel Belvedere, Rifugio Alpenrose, etc.).
- **Interactive Territory Radar:** Physical presence map and coverage of Trentino ski towns (Andalo, Molveno, Fai della Paganella, Cavedago, Spormaggiore).
- **Interactive Features:**
  - Dynamic Product Switcher (Gootel PMS vs Appetito Cloud POS)
  - Interactive ROI & Time Savings Calculator
  - Top Glowing Scroll Progress Bar
  - Animated Number Counters on Scroll
  - Hero Animated Scroll Prompt
  - Verified Client Case Study Modals
  - Interactive FAQ Accordion
  - Fast Demo Request & Consultation Modals
- **100% Smartphone Responsive:** Native horizontal touch swipe tabs, full-screen blur drawer menu, responsive typography, and mobile-optimized touch targets down to 360px.

## Technology Stack
- Semantic HTML5
- Pure Vanilla CSS (custom design system, zero external framework overhead)
- Vanilla JavaScript (reactive UI, translation engine, IntersectionObserver animations)

## Local Development
To preview locally:
```bash
python3 -m http.server 4173
# Or using npx
npx serve .
```
Open [http://localhost:4173](http://localhost:4173) in your browser.
